# Ravula Manohar Yadav — Personal Portfolio

Production-ready, lightweight, zero-framework personal developer portfolio for **Ravula Manohar Yadav** (Full Stack Developer & Founder @ Maniora).

## 🚀 Tech Stack
- **HTML5**: Semantic tags, accessible structure, OpenGraph & Twitter SEO metadata.
- **Tailwind CSS & Custom CSS**: Custom dark editorial theme variables (`--bg: #0c0d0e`, `--accent: #ef4444`).
- **Vanilla JavaScript**: Pure zero-dependency interactive scripts (`main.js`, `projects.js`, `animations.js`).
- **Assets**: Standardized resume PDF document at `assets/resume.pdf`.

## 🎨 Theme & Identity
- **Visual Theme**: "ENGINEERING / SYSTEMS / DIGITAL CRAFT"
- **Typography**: Space Grotesk (primary sans-serif) + JetBrains Mono (technical monospace).
- **Identity Hierarchy**:
  1. Full Stack Developer
  2. MERN / React / Node.js Developer
  3. Founder @ Maniora
  4. Content Creator
